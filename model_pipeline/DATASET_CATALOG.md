# Public dataset catalog and selection record

This catalog records the research scan behind the model pipeline. “Direct” means the training script can retrieve a stable file without an interactive account. A dataset is not considered suitable merely because it is downloadable: the label definition, provenance, licence, geography and leakage boundary must be visible.

## Decision

Zenodo LendingClub is the primary source because it is real, openly downloadable, CC BY 4.0, large enough for a stable held-out test, and explicitly filtered to application-time variables plus a final outcome. It also exposes a real FICO field, allowing the two requested evaluation tasks to use one provenance chain without joining unrelated datasets.

The source is still not an India dataset. The correct claim is therefore: **the pipeline demonstrates reproducible modeling mechanics on a public US benchmark; it does not establish performance for Indian migrants, remittance customers, or any lending corridor.** India-specific RBI/data.gov.in sources are retained for contextual research, not treated as individual evidence.
